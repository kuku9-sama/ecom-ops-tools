# 示例数据

导入和对账用的合成测试数据，不含真实客户或平台数据。

这些文件主要用在两处：

- 导入校验：`orders.csv` 和 `products.csv` 里既有能导入的行，也有必须拒绝的行。
- 对账：`bills.csv` 和 `fx_rates.csv` 覆盖匹配、舍入、汇率缺失、重复账单、账单内部不一致等场景。

下面的“预期行为”就是规格。如果代码和这里不一致，要有意识地改一个，而不是让代码碰巧算对。
